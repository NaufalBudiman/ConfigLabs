# ConfigLabs

Free multi-vendor network config generator with a visual topology builder.

Live: https://configlabs.online

- Config Builder: 25+ templates for H3C Comware 7, Cisco IOS, IOS-XE and NX-OS
- Topology Builder (beta) and WiFi Heatmap Planner (beta)
- Optional Google login to save configs and topologies

Stack: static frontend + Flask API (Vercel) + Neon Postgres.
